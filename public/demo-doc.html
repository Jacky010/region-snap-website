REGION-SNAP · IFRAME DEMO

跨域预览里的文档，也能框选截图。

这是嵌入在 iframe 中的演示页。先共享当前标签页，再框选；需要长图时，在选区内缓慢滚动并拼接。

为什么需要共享标签页？ 浏览器不允许页面脚本读取跨域 iframe 的像素。region-snap 通过共享当前标签页，从屏幕实际画面裁剪选区。

01 · 可见区域截图

开启共享后切换到「框选」模式，拖动选中想留下的区域，即可导出当前可见画面。选区框、遮罩和工具栏不会出现在结果里。

适合合同预览、Office Online、第三方看板等 html2canvas 无法渲染的内容。

02 · 滚动拼接长图

当内容高于一屏时，框选后点击「滚动截图」。iframe 恢复可滚动，在选区内向下滚动，组件会比对相邻帧并拼成一张长图。

  • 滚动速度适中，保持相邻帧有重叠
  • 滚动太快时会提示往回滚一点
  • 尽量不要框进吸顶表头或悬浮工具条
  • 长图高度上限约 16384 像素

03 · 继续往下滚

下面留出足够高度，方便你体验滚动拼接。每一段都有独立标题，方便对照长图结果。

SECTION A 产品更新说明：框选交互、八向调整、边缘自动滚动与触屏长按。

SECTION B 输出格式支持 Data URL、Blob 与 File，可直接接入预览、上传或 OCR。

SECTION C Vue / React / 原生 JS 同一套核心逻辑，样式自动注入，也可用 CSS 变量覆盖。

04 · 更多示例段落

真正的截图发生在浏览器本地。共享期间浏览器会显示「正在共享此标签页」提示条，用完记得停止共享。

桌面端 Chrome / Edge 支持该能力，需 HTTPS 或 localhost。只能截到屏幕上可见的部分，盖在选区上的弹窗也会被拍进去。

提示 先在下方多滚一段，确认文档可以滚动；再回到上方开启共享并框选整块内容区域。

05 · 附录

附录用于拉长页面。滚动截图时从章节标题滚到页脚，可以清楚看到拼接后的连续内容。
